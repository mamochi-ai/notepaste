# 3分小説生成エンジン Ver.0.1

その日の歩数を入力すると、歩数に応じて文章のテンポ（文の長さ・描写の密度・段落・展開）が変わる、日本語の短編小説（約1,000〜1,400字）を生成します。
AI API・サーバー・従量課金は使いません。ブラウザだけで動きます。

完成済みの小説を選ぶのではなく、**人間が書いた物語の骨格と場面の文章を、人物・舞台・時間・伏線の状態を管理しながら組み立てる**方式です。
方式を選んだ理由と限界は [docs/analysis.md](docs/analysis.md)、設計は [docs/architecture.md](docs/architecture.md) にあります。

## 使い方

ES モジュールを使うので、`index.html` をファイルとして直接開くのではなく、HTTP サーバー経由で開いてください。

- **GitHub Pages**：リポジトリの Settings → Pages で公開元をこのブランチのルートにすると、そのまま動きます（ビルド不要）。
- **Codespaces / ローカル**：`npm run serve`（Python の簡易サーバー）を実行し、ポート 8000 を開きます。

実験画面でできること：

- 歩数の入力、ジャンルの自動選択（または指定）、物語の生成・再生成
- 文字数・読了時間の目安・テンポの表示
- 「生成に使用した設定」：ジャンル、テーマ、骨格、舞台、人物、モチーフ、各場面の分岐、結末、文章の指標、自動検査の結果
- テキストファイルとして保存
- **シード**：同じシードのまま歩数だけ変えると、同じ物語のテンポだけが変わります。URL（`?steps=…&seed=…`）でも再現できます。

## テストと品質レポート

Node.js 18 以上が必要です（外部パッケージは不要）。

```sh
npm test         # 単体テスト・データ検査・品質検証（51編）
npm run report   # reports/ に品質レポートと人間評価シートを出力
node scripts/sample.js 5000 myseed ホラー   # 1編だけ生成して設定と検査結果を表示
```

- `reports/quality-report.md`：文字数、検査結果、テンポ帯ごとの指標、類似度、全物語の一覧
- `reports/human-eval.md` / `human-eval.csv`：自動では測れない文学的な品質を人間が採点するためのシート

## データの追加

- 物語の骨格：`src/data/skeletons/*.js` に追加し、`src/data/index.js` に登録します。書式は docs/architecture.md を参照。
- 本文データには「私」「僕」「俺」「彼」「彼女」を直接書かず、`{P}` `{P.pr}` `{B.pr}` などの変数を使います（テストで検査されます）。
- 追加後に `npm test` を実行すると、全組み合わせの描画、未定義フラグ、結末の到達可能性が自動で検査されます。

## 構成

```
index.html, style.css     実験画面
src/engine/               生成エンジン（乱数・テンポ・テンプレート・条件・組み立て・検査）
src/data/                 ジャンル・テーマ・人物・舞台・モチーフ・情景文・骨格
test/                     node:test によるテスト
scripts/                  品質レポート・サンプル生成
docs/                     分析・設計
reports/                  生成済みのレポート
```
