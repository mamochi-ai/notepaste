# アーキテクチャとデータ構造

## 全体の流れ

```
歩数 ──► テンポ t (0〜1) ──────────────────────────┐
シード ─► 乱数                                        │
                                                      ▼
ジャンル ─► 骨格 ─► テーマ・舞台・時間・季節・天候・人称・人物・モチーフ  = 物語の状態 (state)
                    │
                    ▼
              場面 (beat) を順に処理
                ├ 条件 (when) に合う変種だけを候補にする
                ├ 選んだ変種のフラグ (sets) を state に書き込む
                ├ テンポ専用の場面は t に応じて入れる／外す
                └ 情景差し込み枠には共通の情景文を条件付きで選ぶ
                    │
                    ▼
              結末：フラグとテーマに合う結末だけを候補にする
                    │
                    ▼
              文字数調整：描写文・情景文を足し引きして 1,000〜1,400字へ
                    │
                    ▼
              段落組み：テンポに応じて段落あたりの文数を変える
                    │
                    ▼
              本文 + 生成設定 (trace) + 自動検査結果
```

すべての乱数はシード付き（同じ歩数・シード・ジャンル指定なら同じ物語）なので、検査結果や人間評価を再現できます。

## ファイル構成

```
index.html, style.css      実験用画面
src/engine/
  rng.js          シード付き乱数
  tempo.js        歩数 → テンポ
  template.js     テンプレート記法の描画
  conditions.js   when 条件の評価
  generator.js    物語の組み立て（状態管理・分岐・結末・文字数調整）
  assemble.js     段落組み・文字数カウント
  analyze.js      自動検査（UI・テスト・レポート共通）
src/data/
  genres.js themes.js characters.js places.js motifs.js interludes.js
  skeletons/*.js  物語の骨格（ジャンルごと）
test/             node:test による単体テスト・データ検査・品質検証
scripts/report.js 品質レポートと人間評価シートの出力
```

## 8つの要素とデータの対応

| 要素 | データ | 役割 |
|---|---|---|
| ジャンル | `genres.js` | 自動選択の単位。歩数とは無関係に選ぶ |
| テーマ | `themes.js` ＋ 骨格の `themes` | 結末・余韻の文を切り替える |
| 登場人物 | `characters.js` ＋ 骨格の `roles` | 役割（主人公P・相手B）の制約（年齢層・世界観）で選ぶ |
| 舞台 | `places.js` | 骨格が求めるタグで選ぶ。舞台固有の感覚描写を持つ |
| 物語の骨格 | `skeletons/*.js` | 場面の並び、使える舞台・時間・モチーフ |
| 展開の分岐 | 場面の `variants` ＋ `sets` / `when` | 分岐でフラグを立て、後の場面と結末が参照する |
| 文体 | 人称（一人称／三人称）＋ テンポ | 主人公の呼び方、文の長短、描写密度、段落 |
| 結末 | 骨格の `endings` | フラグとテーマの条件に合うものだけ選ぶ |

## 骨格のデータ構造

```js
{
  id: 'shop_last_day',
  genres: ['日常'],
  themes: ['farewell', 'inherit'],
  world: 'modern',                 // 人物・舞台・情景文の世界観
  placeTags: ['shop'],             // 舞台の絞り込み
  times: ['夕方', '夜'],           // 舞台の times と交差させる（null なら時間帯を使わない）
  seasonal: true,                  // 季節・天候を使うか
  motifTag: 'display',             // モチーフの絞り込み
  persons: ['first', 'third'],
  roles: {
    P: { age: ['young', 'adult'] },
    B: { age: ['old'], ref: '{B.sei}さん', introducedAt: 'enter' },
  },
  titles: ['閉店の日', '{M}の約束'],
  beats: [
    { id: 'opening', variants: [ { id: 'a', lines: [...] }, { id: 'b', lines: [...] } ] },
    { id: 'walk', interlude: { tags: ['outdoor'], count: 1 } },
    { id: 'kids', tempo: 'fast', variants: [...] },     // テンポが速い日だけ
    { id: 'look', tempo: 'slow', variants: [...] },     // テンポが遅い日だけ
    { id: 'turn', variants: [
        { id: 'remembered', sets: { remembered: true }, lines: [...] },
        { id: 'priced',     sets: { remembered: false }, lines: [...] } ] },
  ],
  endings: [
    { id: 'keep', when: { flags: { remembered: true }, theme: 'inherit' }, lines: [...] },
  ],
}
```

### 文（line）の書式

```js
'必須の文。'                                   // 常に入る
'¶'                                            // 段落の区切り
{ t: '通常の文。', fast: '短い版。', slow: '長い版。' }  // テンポで版を選ぶ
{ t: '描写の文。', detail: true }               // 削除可。テンポと文字数調整で増減
{ t: '雨の日だけの文。', when: { weather: ['雨'] } }
```

### テンプレート記法

| 記法 | 意味 |
|---|---|
| `{P}` | 主人公（一人称なら一人称代名詞、三人称なら名前） |
| `{P.pr}` | 主人公の代名詞（一人称なら「私」等、三人称なら「彼／彼女」） |
| `{P.name}` `{P.sei}` `{P.I}` `{P.feature}` | 名・姓・会話での一人称・外見の特徴 |
| `{B}` / `{B.pr}` | 相手（`ref` の呼び方）／代名詞。三人称で主人公と同性のときは代名詞を使わず `ref` にする（曖昧さ回避） |
| `{P^男性形|女性形}` | 性別で切り替える語（例 `{P^くん|ちゃん}`） |
| `{M}` `{M.desc}` `{M.act}` … | モチーフ |
| `{S}` `{S.short}` `{S.smell}` … | 舞台 |
| `{T}` `{SEASON}` `{W}` | 時間帯・季節・天候 |
| `[[A|B|C]]` | 小さな言い換え（ランダム） |

本文データには「彼」「彼女」「私」「僕」「俺」を直接書かない規則とし、テストで検査します。

## 歩数とテンポ

`t = log10(歩数/1000 + 1) / log10(21)`（0〜1に丸める。2万歩で1）

| 帯 | 目安 | 描写文 | 段落あたりの文数 | 追加場面 |
|---|---|---|---|---|
| ゆったり | 〜約2,500歩 | 多い | 最大5〜6文 | 内省の場面 |
| ふつう | 約2,500〜7,500歩 | 中 | 3〜4文 | 物語ごとに、内省か動きのどちらか一方 |
| きびきび | 約7,500歩〜 | 少ない | 2文 | 動きのある場面 |

帯の名前は優劣を感じさせない語にしています。ジャンル・骨格の選択には歩数を使いません。

乱数は「判断ごとに独立した系列」（ジャンル、骨格、人物、各場面の分岐…）から引きます。
そのため **同じシードで歩数だけを変えると、同じ物語のテンポだけが変わります**。実験画面とテストはこの性質を使って、テンポの違いを比較しています。

## 自動検査（analyze.js）

| 検査 | 方法 |
|---|---|
| 文字数 | 空白・改行を除いて 1,000〜1,400字 |
| 文章の重複 | 同一物語内の同一文、物語間の5文字シングルの Jaccard 類似度 |
| 人物の設定矛盾 | 未登場人物の名前混入、一人称視点での主人公名の地の文混入、紹介前の名前使用、本文データの代名詞直書き |
| 不自然な接続 | 未解決の変数、句読点の重複、括弧の不一致、同じ文末の連続、同じ接続詞の連続 |
| 展開と結末 | 結末の条件とフラグの一致、モチーフの前半提示と後半回収 |
| 歩数による違い | 平均文長、段落密度、描写文の比率をテンポ帯ごとに比較 |
| ジャンルの多様性 | 自動選択での出現分布 |
